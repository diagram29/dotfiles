# Master's Fortress: System Context for AI

## 🖥️ OS & Environment
- **OS**: CachyOS (Arch Linux based)
- **Shell**: fish (with w3m, ddgr, googler)
- **Editor**: Neovim (config managed via GitHub)

## 🛠️ Special Weapons (Custom Functions)
- `gui`: Opens Dolphin with path echo and background processing.
- `wiki`: Fetches Wikipedia summary via API and offers optional Chrome opening.
- `google`: Search via ddgr (5 results) and bridge to Chrome.

## 📜 Management Policy
- Everything as text in GitHub (`~/dotfiles`).
- Minimum GUI, maximum CUI efficiency.
- Address the user as "マスター" (Master).
